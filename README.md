## 👋 About me

- 🧩 **Full stack, both ends done properly** — React and Next.js in TypeScript on the front, Node.js, NestJS, Go, and FastAPI behind it. I own features from the component tree down to the query plan.
- 📡 **Real-time and IoT platforms** — three years on systems that collect, normalize, analyze, and display data from connected devices, with ingestion adapters for MQTT, Modbus, BACnet, and WebSockets feeding one unified schema.
- 🌊 **Event-driven and data-heavy by habit** — Kafka and Pub/Sub pipelines, Spark and PySpark analytics, ETL into BigQuery and Snowflake. Idempotency, retries, and dead-letter handling are part of the feature, not a follow-up ticket.
- 🤖 **AI-integrated products** — RAG, agentic workflows, and MCP wired into real applications using LangChain, Pinecone, OpenAI, Gemini, and Claude. Most of the work is retrieval quality and grounding, not prompts.
- 🛠 **Polyglot backend** — Go, Python, Java, and C# alongside Node, which means I'm comfortable being dropped into an unfamiliar service and making it make sense.
- 🎯 **Currently** — freelancing on warehousing, logistics, and e-commerce platforms, and open to senior full-stack and backend roles.
